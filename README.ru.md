# domains2rules

[English](README.md) · **Русский**

Превращает простой список доменов в компактные regex-правила AdGuard
(`$dnsrewrite`): вместо сотен строк `||domain^$dnsrewrite=IP` — несколько строк
вида `/^([^.]+\.)*(a\.com|(x|y)\.b\.com|…)$/$dnsrewrite=IP`.

Без зависимостей, только стандартная библиотека Python 3.8+.

## Использование

```bash
./domains2rules.py                                  # без аргументов — справка
./domains2rules.py domains.txt -i 1.2.3.4 -o rules.txt
./domains2rules.py domains.txt -i 1.2.3.4 -i 5.6.7.8 -i 9.9.9.9
cat domains.txt | ./domains2rules.py -i 1.2.3.4 > rules.txt
```

| Параметр | Описание |
|---|---|
| `-i`, `--ip IP` | **Обязательный.** IP для `$dnsrewrite`; можно повторять. Порядок строк в выводе = порядок аргументов |
| `-o`, `--output FILE` | Выходной файл (по умолчанию stdout) |
| `--max-len N` | Макс. длина одной строки-правила в байтах. По умолчанию **1024**; `0` — не разбивать |
| `--no-eol` | Не добавлять перевод строки в конец файла |
| `--no-check` | Пропустить самопроверку |
| `--lang {en,ru}` | Язык сообщений. По умолчанию: `DOMAINS2RULES_LANG`, затем локаль системы (`ru*` → русский, иначе английский) |

## Входной формат

Лишнее вычищается автоматически: `example.com`, `*.example.com`,
`||example.com^`, URL, hosts-строки (`0.0.0.0 example.com`), комментарии
`#` и `!`, пустые строки. Кириллические домены переводятся в punycode.
Некорректные строки пропускаются и перечисляются в stderr.

## Что делает

- убирает дубли и домены, уже покрытые родителем (`api.x.com` при наличии `x.com`);
- группирует поддомены: `(a|b|c)\.example\.com`;
- сворачивает числовые серии (`dnstest0…10`) и одинаковые имена в разных TLD
  (`brand\.(ca|com|net)`);
- режет правило на куски ≤ `--max-len` байт; для каждого куска пишет по строке на IP;
- перед записью проверяет результат: все домены и их поддомены матчатся, похожие
  имена (`xexample.com`) — нет, конструкции только RE2-совместимые.
  При ошибке — код выхода 1, файл не пишется.

Порядок вывода: сначала кусок regex, внутри — IP в заданном порядке.

## Про лимит длины

1024 байта — консервативное значение по умолчанию. Точный лимит длины правила
зависит от продукта и версии AdGuard: если правила не принимаются — уменьши
`--max-len`, если принимаются — можно увеличить, чтобы получить меньше строк.

## Проверка

```bash
python3 -m unittest discover -s tests -v
./domains2rules.py examples/domains.txt -i 1.2.3.4
```

Результат: одна regex-строка на IP, самопроверка `OK` в stderr.
